# 18. 접근성

프리미티브가 대신 해주는 것들

---

## 왜 이 장이 필요한가

<v-clicks>

- 접근성은 "추가 기능"이 아니라 **기본 품질**이다
- 그런데 직접 구현하면 **정말 어렵다** — 포커스 트랩, 롤 관계, 키보드 규약
- shadcn/ui를 쓰면 **상당 부분이 이미 되어 있다.** 무엇이 되어 있는지 알아야 망치지 않는다
- 공공기관·금융·대기업 프로젝트에서는 **법적 요구사항**이기도 하다

</v-clicks>

<v-click>

<div class="pt-4 text-lg">
이 장의 목표: <strong>공짜로 받는 것을 실수로 깨뜨리지 않기.</strong>
</div>

</v-click>

---

## 프리미티브가 해주는 것

Dialog 하나를 직접 만들면 이만큼을 구현해야 한다.

<v-clicks>

- `role="dialog"` + `aria-modal="true"`
- 열릴 때 **포커스를 안으로 이동**, 닫힐 때 **원래 위치로 복원**
- **포커스 트랩** — Tab이 다이얼로그 밖으로 나가지 않게
- **Esc로 닫기**
- 바깥 클릭으로 닫기 (단, 드래그 시작이 안이면 제외)
- 배경 스크롤 잠금 + **스크롤바 폭만큼 레이아웃 보정**
- `aria-labelledby` / `aria-describedby`를 제목·설명과 연결
- 열린 동안 배경 콘텐츠를 `aria-hidden`으로

</v-clicks>

<v-click>

<div class="pt-2 text-lg">
Base UI / Radix / React Aria가 <strong>이 전부를 처리</strong>한다.
</div>

</v-click>

## 키보드만으로 조작하기

브라우저에서 **마우스를 치우고** 앱을 써보는 것이 가장 빠른 점검법이다.

| 키 | 기대 동작 |
|---|---|
| `Tab` / `Shift+Tab` | 다음/이전 포커스 가능 요소 |
| `Enter` / `Space` | 버튼 실행 |
| `Esc` | 다이얼로그·팝오버 닫기 |
| `↑` `↓` | 메뉴·셀렉트 항목 이동 |
| `Home` / `End` | 목록 처음/끝 |
| 문자 입력 | 해당 글자로 시작하는 항목으로 점프 |

<v-click>

<div class="pt-3">
이 표의 동작이 <strong>Select, DropdownMenu, Tabs, Combobox에서 전부 공짜로</strong> 나온다.
직접 만들면 하나하나 구현해야 한다.
</div>

</v-click>

## 포커스 링을 지우지 말 것

가장 흔하고 가장 해로운 실수다.

```css
/* ❌ 절대 하지 말 것 */
*:focus { outline: none; }
```

<v-clicks>

- 키보드 사용자가 **자기가 어디 있는지 알 수 없게** 된다
- 디자인이 안 예쁘다는 이유로 지우는 경우가 대부분인데, 대안이 있다

</v-clicks>

<v-click>

```css
/* ✅ 마우스 클릭에는 안 보이고, 키보드 이동에만 보인다 */
:focus-visible { outline: 2px solid var(--ring); outline-offset: 2px; }
```

</v-click>

<button class="ui-btn ui-btn--outline">설정</button>
</UiSurface>
<UiSurface label="키보드 Tab — 링 표시">
<button class="ui-btn ui-btn--outline" data-focus>설정</button>
</UiSurface>
</div>

## 폼 접근성 — 라벨과 오류

```tsx
// shadcn/ui의 Form 컴포넌트가 자동으로 연결해 준다
<FormField
  control={form.control}
  name="email"
  render={({ field }) => (
    <FormItem>
      <FormLabel>이메일</FormLabel>       {/* htmlFor 자동 */}
      <FormControl>
        <Input {...field} />              {/* id, aria-invalid, aria-describedby 자동 */}
      </FormControl>
      <FormDescription>회사 이메일을 입력하세요</FormDescription>
      <FormMessage />                     {/* role="alert" */}
    </FormItem>
  )}
/>
```

<v-clicks>

- `<Label htmlFor>` ↔ `<input id>` 연결이 **자동**이다
- 오류가 생기면 `aria-invalid="true"`와 `aria-describedby`가 붙는다
- 스크린리더가 **"이메일, 편집, 유효하지 않음, 올바른 형식이 아닙니다"**로 읽는다

</v-clicks>

## 아이콘 버튼에는 이름을 준다

```tsx
// ❌ 스크린리더가 "버튼"이라고만 읽는다
<Button size="icon"><TrashIcon /></Button>

// ✅ 방법 1 — aria-label
<Button size="icon" aria-label="삭제">
  <TrashIcon />
</Button>

// ✅ 방법 2 — 시각적으로만 숨긴 텍스트
<Button size="icon">
  <TrashIcon />
  <span className="sr-only">삭제</span>
</Button>
```

<v-click>

<div class="pt-2">
<code>sr-only</code>는 <strong>화면에서는 안 보이지만 스크린리더는 읽는</strong> 유틸리티다.
<code>display: none</code>과 다르다 — 그건 스크린리더도 못 읽는다.
</div>

</v-click>

## 동적 콘텐츠 알리기

화면이 바뀌었는데 포커스가 그대로면 스크린리더 사용자는 모른다.

```tsx
// 토스트·알림 — role="status" 또는 aria-live
<div role="status" aria-live="polite">
  3개 항목이 저장되었습니다
</div>

// 긴급한 오류 — assertive (읽던 것을 끊고 알린다)
<div role="alert">
  저장에 실패했습니다
</div>
```

<v-clicks>

- `polite` — 읽던 것이 끝나면 알린다. **대부분 이걸 쓴다**
- `assertive` — 즉시 끊고 알린다. **오류에만** 쓴다
- shadcn/ui의 `Toast`, `Sonner`가 이미 처리해 준다

</v-clicks>

## 모션 줄이기

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

<v-clicks>

- 전정기관 장애가 있는 사용자에게 큰 모션은 **어지럼증을 유발**한다
- OS 설정을 켜둔 사용자에게만 적용된다
- Tailwind에는 `motion-reduce:` 변형이 있다

</v-clicks>

```html
<div class="transition-transform motion-reduce:transition-none">
```

## 실수로 깨뜨리는 것들

<v-clicks>

- **`<div onClick>`** — 키보드로 접근 불가. `<button>`을 쓴다
- **`outline: none`** — 포커스 링 제거
- **placeholder를 라벨 대신** — 입력하면 사라져서 무엇을 넣는지 알 수 없다
- **`aria-hidden`을 포커스 가능한 요소에** — 보이는데 스크린리더는 모르는 상태
- **`asChild`/`render`로 태그를 바꾸며 의미를 잃음** — 버튼을 `<div>`로 렌더
- **자동 재생·자동 캐러셀** — 읽는 중에 내용이 바뀐다

</v-clicks>

## 18장 요약

<v-clicks>

- 프리미티브가 **포커스 트랩·키보드 규약·ARIA 관계**를 대신해 준다
- 목표는 그것을 **실수로 깨뜨리지 않는 것**
- `:focus-visible`을 쓰고 **포커스 링을 지우지 않는다**
- **색만으로 정보를 전달하지 않는다** — 텍스트를 함께
- 아이콘 버튼에는 `aria-label` 또는 `sr-only` 텍스트
- 동적 알림은 `role="status"`(polite) / `role="alert"`(assertive)
- **마우스 없이 써보는 것**이 가장 효과적인 단일 테스트

</v-clicks>
